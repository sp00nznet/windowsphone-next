# windowsphone-next

develop a series of powershell scripts or windows 11 image creation steps that makes windows 11 capable of running on this device https://up-board.org/upcore/specifications/. The system will utilize a LattePanda 3 Delta 864. and a PiSugar2 Plus for power. It will have a 4:4 720x720 screen. It use a EM06-A LTE card for a phone interface. I will need a launcher that lets me open applications. the launcher will need to fit this specific resolution, 720x720. it will take over the screen on boot. the first application will be a dialer app. this will tell the EM06-A to make phone calls using AT commands and whatever else is required. The next application will be a Messaging App. This will allow text/sms messages to be sent via the EMO06-A card. everything will need to maintain the 720x720 aspect ratio. look good. look modern.
